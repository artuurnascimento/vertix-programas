# Vertix — programas para Windows

Instaladores oficiais dos programas desenvolvidos pela **Vertix** (vertix.studio).

Este repositório guarda **somente os arquivos de instalação** publicados em
[Releases](../../releases) — não contém código-fonte nem dados de clientes.

| Programa | Para quem |
|---|---|
| Caio José Despachante | Equipe do escritório Caio José Despachante |
| Vinícius Leal Despachante | Equipe do escritório Vinícius Leal Despachante |

Os programas se atualizam sozinhos a partir daqui. Se precisar instalar de novo,
baixe o arquivo `.exe` do seu escritório na versão mais recente em Releases.

Dúvidas: fale com a Vertix.
